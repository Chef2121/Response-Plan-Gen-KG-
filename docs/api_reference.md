# API Reference

## Core Components

### GraphState
- Main state management for the workflow

### Tools
- `neo4j_tools`: Database interaction tools
- `event_tools`: Event processing utilities
- `plan_tools`: Response planning functions
- `storage_tools`: Data persistence utilities

### Workflows
- `nodes`: Core workflow functions
- `routing`: Workflow routing logic
- `graph`: Main workflow orchestration

### Agents
- `traffic_agent`: Main traffic management agent
